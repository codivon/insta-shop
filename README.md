# 🛍️ InstaShop — فروشگاه اینستاگرامی

پلتفرم فروشگاهی مبتنی بر اینستاگرام با سه پنل مجزا:

| پنل | نوع نمایش | توضیح |
|---|---|---|
| 👑 **مدیریت (Admin)** | دسکتاپ + ریسپانسیو موبایل | تنظیمات سیستم، مدیریت کل پلتفرم |
| 🏪 **فروشنده (Seller)** | موبایل‌اپ (App-like) | مدیریت فروشگاه، محصولات، سفارش‌ها |
| 🛒 **مشتری (Customer)** | موبایل‌اپ (App-like) | خرید، سبد خرید، پیگیری سفارش |

## ✨ ویژگی‌های کلیدی

- 🔐 احراز هویت با **شماره موبایل + کد OTP** (مشتری و فروشنده)
- 📸 ثبت‌نام فروشنده با **شناسه اینستاگرام**
- 🧩 **سه Session کاملاً مستقل** برای هر پنل (بدون تداخل ورودها)
- 📱 **PWA مجزا** برای اپ فروشنده و اپ مشتری (قابل نصب روی گوشی)
- 🎨 **تم روشن/تیره** + رنگ‌بندی کاملاً قابل شخصی‌سازی از پنل مدیریت
- 💳 درگاه‌های پرداخت ایرانی از طریق پکیج **shetabit/payment** (زرین‌پال، زیبال، آیدی‌پی و ...)
- 📨 ارسال پیامک با چند **پروایدر** (کاوه‌نگار، فراز اس‌ام‌اس، ملی‌پیامک، ... + حالت لاگ برای تست)
- 🌐 **فارسی و راست‌چین (RTL)** با حس SPA

## 🚀 راه‌اندازی سریع

```bash
# 1) راه‌اندازی MySQL (نصب کاربر-محلی، بدون نیاز به روت)
~/.local/start-mysql.sh

# 2) اجرای سرور توسعه
cd /home/z/insta-shop
php artisan serve --host=0.0.0.0 --port=8000
```
